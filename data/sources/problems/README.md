# ICPC World Finals problem corpus

Statements extracted from the official PDFs:

- https://icpc.global/worldfinals/past-problems
- 2025: https://worldfinals.icpc.global/problems/2025/finals/problems/

One directory per final, 1999–2025. Each problem has a Markdown file with
front matter and the extracted statement. The PDFs are **not** stored in this
repository; they live in the local corpus:

    /home/yudivian/Workspace/ICPC/problems_pdfs/

`index.csv` per year maps letter, title, Markdown, local PDF and source pages.
`manifest.csv` is the global index with source URLs and checksums. PDFs are
ignored by git; do not add them.
